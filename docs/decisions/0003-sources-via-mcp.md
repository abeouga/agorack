# 0003 部品は MCP だけでつなぎ、根拠の外枠をそろえる

- 状態：決定
- 日付：2026-11-09

## 決めること

部品（文之助・カブロガー など）と Agorack のつなぎ方と、答えの根拠の形。

## 背景

- 部品はそれぞれ自分の画面・API・データを持ち、言語や置き場所も違う。
- 部品が増えても、Agorack の中心（会話のループ・画面）を変えずに済むようにしたい。
- 答えには、どの部品のどこから取った値かを示したい。

## 決定

1. **つなぎ方**：部品とは MCP だけでつなぐ。つなぐ部品は設定ファイル（`config/sources.json`）に書き、`stdio`（手元で起動）と `http`（Streamable HTTP）の両方に対応する。
2. **道具の名前**：Claude に渡す道具の名前は `<部品のid>__<道具の名前>` にし、部品をまたいだ重なりを防ぐ。
3. **部品の説明**：各部品の MCP サーバーが公開する説明（`instructions`）を、部品の名前を付けて指示に足す。部品ごとの使い方は部品が持ち、Agorack には書かない。
4. **根拠の外枠**：部品の MCP は、根拠を `kind`・`source_id`・`label`・`location`・`value` の形で返す。Agorack はこの外枠だけを見て根拠を取り出し、`location` の中身は解釈しない。画面は `kind` ごとに表示を選ぶ。

## 影響

- 部品を足すときに Agorack で変えるのは、設定と、新しい `kind` の表示だけで済む。
- 部品の側は、根拠の外枠を守る必要がある。カブロガーの MCP もこの形にそろえる。
- 部品の `source_id`（記録の ID）と Agorack の部品の id が混ざらないよう、Agorack の型では記録の ID を `recordId` と呼ぶ。
