# 0002 道具を使うループを自分で回す

- 状態：決定
- 日付：2026-11-09

## 決めること

Claude に道具（部品の MCP の tool）を使わせるループを、どこで回すか。

## 背景

- 答えの根拠（どの部品の、どの書類・区間か）を、道具が返るたびに取り出して画面に流したい。
- 部品の MCP サーバーは、最初は手元の PC で標準入出力で動く。
- 道具の呼び出しの回数の上限・停止・失敗の扱いを、Agorack の規則として決めたい。

## 選択肢

| 案 | 内容 | 合わない点 |
|---|---|---|
| 自分で回す | Messages API を呼び、`tool_use` を受けたら Agorack が MCP を呼んで `tool_result` を返す | ループの規則を自分で書く必要がある（量は少ない） |
| SDK の Tool Runner | SDK が呼び出しと繰り返しを自動で行う | 道具ごとの根拠の取り出しと画面への流し込みを、フックで差し込む形になる |
| Messages API の MCP コネクター | Claude 側が部品の MCP サーバーを直接呼ぶ | 部品を公開の住所に置く必要がある。手元の標準入出力のサーバーは呼べない。道具の結果を Agorack が受け取れないので、根拠を取り出せない |

## 決定

ループは Agorack のサーバー（`apps/server/src/agent/`）で自分で回す。

- ループは「モデルを呼ぶ」「道具の一覧と呼び出し」の2つのポートだけに依存し、Claude の SDK と MCP の SDK は、それぞれの実装（`model/anthropic/`・`sources/`）に閉じ込める。
- 道具の選び方は `auto` にする（特定の道具を強制しない）。

## 影響

- ポートを偽物に替えて、ループの規則（並行・失敗・上限・停止）を確かめられる。
- モデルや部品のつなぎ方を替えても、ループの規則は変わらない。
