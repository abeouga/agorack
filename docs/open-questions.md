# 次に決めること

部品（文之助・カブロガー）を Agorack にまとめていくうえで、まだ決めていないことの一覧。決めたら、決めごとの記録（[decisions/](decisions/)）を書き、ここの項目に印を付けて、その記録へのリンクを足す。

各節の番号の Issue で話し合い、全体は Epic の #52 で追う。チェックリストは Issue の側を正とし、決まったらここにも反映する。

日付：2026-11-14

## 目指す形（前提）

- 利用者が開くのは Agorack だけにする。文之助は単独のアプリとしての入口（メニュー・チャット）を持たず、画面は Agorack の中に埋め込んで出す。
- 部品のコードは部品のリポジトリに置いたまま、Agorack とは MCP・HTTP API・埋め込み（iframe と postMessage）だけでつなぐ。
- 一覧・メニュー・チャット・ダイアログなど、どの部品にも共通のものは Agorack が描く。部品に固有の画面（帳票の確認と修正、走行の地図など）は部品が描く。
- データは部品ごとに別々に保存する。

## 6. 埋め込みの決まり（#48）

- [ ] 埋め込みは1段までにし、部品は部品を埋め込まない

- [ ] 部品どうしを直接つながない（部品をまたぐ表示はライブラリかチャットで行う）
- [ ] 高さの伝え方（例：`embed:resize`）と、Agorack の URL から埋め込みの住所を作る形（再読み込み・リンクの共有で同じ画面に戻れる）
- [ ] 色・文字の大きさ・明暗のテーマを Agorack から部品へ渡す方法
- [ ] 同時に開く iframe の数の上限（右の欄とダイアログの2つまで、など）
